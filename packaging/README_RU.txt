RDR2 COOP — COMBAT-05, ПЕРВЫЙ ТЕСТ ДВУХ ПК

Это экспериментальная сборка на основе JuliPodie/rdr2-coop-story (MIT).
Включает локальные исправления Combat-01–05 и выбор Epic Games с ручным запуском.
Полное совместное прохождение и работа Steam–Epic пока НЕ подтверждены.

ВАЖНО ДЛЯ EPIC
Сейчас мод допускает конкретный RDR2.exe версии 1.0.1491.50 и проверяет его SHA256.
Даже одинаковый номер версии не гарантирует одинаковый файл из Steam и Epic.
Если лаунчер сообщает о несовпадении сборки/хеша, остановитесь и передайте текст ошибки разработчику этого теста. Не заменяйте RDR2.exe и не отключайте проверку.

ПЕРЕД УСТАНОВКОЙ
1. Распакуйте ZIP целиком в отдельную папку, например D:\RDR2-Coop-Test.
2. Запустите чистую игру через свой магазин и один раз войдите в сюжет. Затем закройте игру.
3. Сохраните резервную копию своих сохранений. Не начинайте проверку на единственном ценном сохранении.
4. Скачайте Script Hook RDR2 отдельно у Alexander Blade:
   https://www.dev-c.com/rdr2/scripthookrdr2/
   Распакуйте архив. Лаунчер предложит выбрать его папку, содержащую ScriptHookRDR2.dll и dinput8.dll (обычно bin).
   NativeTrainer.asi для этого теста не нужен.
5. Запустите START_COOP.bat. Отдельно устанавливать .NET не требуется.
6. В настройках выберите RDR2.exe из СВОЕЙ папки игры. Не копируйте путь друга из Steam.

RADMIN VPN
Оба игрока входят в одну и ту же сеть Radmin VPN и видят друг друга онлайн.
В поле адреса хоста вводите адрес ИМЕННО ХОСТА, показанный Radmin VPN. Не 127.0.0.1 и не адрес гостя.
Мод использует TCP 43120 и UDP 43121. При запросе Windows разрешите доступ помощнику мода в доверенной сети; не отключайте брандмауэр целиком. Через Radmin проброс портов роутера для этого сценария не нужен.

РОЛИ И ЗАПУСК
Одинаковый ZIP нужен на обоих ПК.
Хост: режим HOST, платформа STEAM (для Steam), адрес хоста из Radmin, сохранение для теста, пароль сессии.
Друг: режим CLIENT, платформа EPIC GAMES, тот же адрес хоста из Radmin и тот же пароль сессии.
Пароль сессии мода — отдельный от пароля сети Radmin.
EPIC GAMES в этом лаунчере сначала подготавливает мод и соединение. После сообщения Session ready запустите RDR2 вручную из библиотеки Epic и выберите сюжет. Лаунчер оставьте открытым.
Для настоящего теста вдвоём НЕ включайте SOLO TEST или Live mirror: это синтетический клон.
Сначала проверьте соединение, ходьбу, прицеливание и оружие в свободном мире. Прохождение миссий этой сборкой ещё не проверено.

ДЛЯ ХОСТА С ПРЕЖНИМ ЛОКАЛЬНЫМ ТЕСТОМ
Перед HOST нужно остановить помощник local-test: он уже занимает порт и канал игры.
Если лаунчер видит существующий CoopStoryBridge.asi как чужую установку, не удаляйте файлы наугад: попросите подготовить переход с локального теста. Этот ZIP не переносит журналы, токены и сохранения хоста.

ОШИБКИ
Если проверка игры не проходит, пришлите текст ошибки; если соединение есть, но персонаж не появляется, экспортируйте диагностику с обоих ПК.
Не входите в Red Dead Online с модом. Script Hook также предназначен для одиночного режима.
