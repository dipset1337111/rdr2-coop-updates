# Проверка подключения через F8

Эта ветка содержит исходники экспериментального меню; это не новый релиз лаунчера. Сборку необходимо собрать из этой ветки и установить обоим игрокам. Sync24 из Releases не содержит этих изменений меню.

1. На обоих ПК закрыть RDR2. В собранном лаунчере включить SETTINGS → CONNECT IN GAME (F8), сохранить настройки. Выбрать сетевой режим и свою платформу. SOLO TEST предназначен для клона, а не подключения друга.
2. Запустить через лаунчер, загрузить Story Mode. Хост выбирает свою кампанию в игре. Гость должен быть вне миссии и катсцены.
3. Хост: F8 → Create session / copy invitation → Enter. Приглашение копируется в буфер. Передать его другу лично, не публиковать: код содержит данные доступа к сессии.
4. Гость: скопировать полное приглашение → F8 → Join with copied invitation → Enter. Radmin VPN должен работать на обоих ПК, в общей сети; хост выбирает свой адрес Radmin в лаунчере.
5. Проверить появление соединения и удалённого игрока. F10 включает техническую строку; по умолчанию она скрыта. Стрелки выбирают пункт, Enter подтверждает, Escape закрывает меню.
6. Проверить пустое/неверное приглашение, отказ подключения во время локальной миссии, остановку сессии. После теста собрать ZIP отчёта с каждого ПК через DIAGNOSTICS FOLDER → Sessions.

Ожидаемый результат: игровой запрос создания/подключения доходит до сетевого процесса, ошибки доступны в меню. Затемнение, автоматическое размещение рядом с хостом и полная синхронизация заданий ещё не реализованы. Сохранения гостя не копируются с хоста. Вход через F8 не означает загрузку кампании хоста.

Автоматические проверки исходников: 105 native, 33 launcher, 72 sidecar. Проверка двух ПК в игре остаётся обязательной.
